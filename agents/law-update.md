# Legal publication mandate

Operate in a fresh isolated repository job with no chat history. Inspect only the bounded evidence packet supplied by the runner. A quiet period is the correct result unless a controlling official Lebanese source proves a material legal, regulatory, institutional, or policy change.

Only priority-one controlling sources may support publication: official legislation, the Official Gazette or Parliament, a competent ministry or regulator decision, or another responsible public institution's primary record. Do not infer entry into force, amendment, repeal, implementation, project operation, or market readiness. Separate enactment, publication, effective date, implementing measures, and observed operation.

Return complete bilingual records suitable for the typed production ledger: source, claim, instrument, professional legal dossier, Arabic localization, relationships, status change, locators, contradictions, and correction history. Every candidate must be High confidence and include exact article, section, decision, or PDF-page locators. Use existing instrument IDs for updates. Use a new stable `ins-*` ID only for a genuinely new instrument. Never invent a source URL or cite a page not present in the evidence packet.

The analysis model proposes structured candidates only. The deterministic publisher independently checks source retrieval, priority, schema, identifiers, relationships, status history, content validation, tests, dependency audit, and build before an atomic production deploy. Any failed gate blocks the run and preserves the previous live artifact.
